# Стандарт PardAiLabs: страница «Рейтинг AI-моделей»

Данный формат является обязательным для всех версий страницы «Рейтинг AI-моделей» на портале PardAiLabs.

## Структура страницы

Страница всегда строится в следующем порядке:

1. Заголовок страницы.
2. Месяц и год последнего обновления.
3. Краткое описание рейтинга и методики.
4. Дата последнего тестирования и информация о следующем обновлении.
5. Таблица «Топ-10 моделей».
6. Блок «Лидеры по категориям».
7. Блок «Как считается итоговая оценка».
8. Таблица весов критериев.
9. Блок «Методика PardAiLabs».

Изменение структуры допускается только при принятии новой редакционной версии стандарта.

---

## Таблица рейтинга

В рейтинге всегда участвуют десять моделей.

Таблица содержит следующие столбцы:

- Место
- Модель
- Итог
- Качество
- Документы
- Русский язык
- Код
- Агенты
- Контекст
- Скорость
- Стоимость

Модели сортируются исключительно по итоговому баллу.

Название модели всегда указывается полностью, с точной версией модели.

---

## Вес критериев

Итоговая оценка является взвешенной суммой.

Используются следующие веса:

- Качество — 22%
- Документы — 14%
- Русский язык — 14%
- Код — 12%
- AI-агенты — 12%
- Длинный контекст — 12%
- Скорость — 7%
- Стоимость — 7%

По критерию «Стоимость» оценка 10 означает наиболее экономичную модель при сопоставимом качестве.

---

## Лидеры по категориям

После основной таблицы всегда публикуются лидеры по отдельным направлениям:

- Лучшее качество
- Лучший код
- Лучшие документы
- Лучшие AI-агенты
- Лучший длинный контекст
- Самая быстрая модель
- Лучшая стоимость

---

## Методика

Каждая модель тестируется по единому набору сценариев.

Используются одинаковые инструкции, одинаковые условия запуска и единые критерии оценки.

Результаты проверяются лабораторией PardAiLabs и публикуются только после завершения полного цикла испытаний.

---

## Обновление рейтинга

При выходе новой версии модели обновляются только:

- значения оценок;
- итоговый балл;
- положение модели в рейтинге;
- дата тестирования;
- список моделей.

Структура страницы, названия блоков, порядок разделов и методика остаются неизменными до принятия новой версии редакционного стандарта.
