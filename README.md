# PardAiLab

Информационно-аналитический портал лаборатории практического искусственного интеллекта. Next.js (App Router), React, TypeScript, Tailwind CSS и компоненты в духе shadcn/ui.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверки:

```bash
npm test
npm run lint
npm run build
```

## Содержание

Разделы: новости, практика, каталог решений, разработка, исследования, рейтинг моделей, каталог AI и поиск по всем четырём типам материалов. Справа внизу — подбор «Подобрать ИИ»: он сопоставляет задачу с редакционной шкалой и каталогом, место в подборе не продаётся.

Оценки моделей считаются в `lib/scores.ts`. Это шкала лаборатории, не академический бенчмарк и не реклама вендоров.

## Редакция

`/admin` — вход и правка статей, сервисов и моделей. После сохранения публичные страницы читают SQLite (`data/pardailabs.db`, каталог не коммитится). При первом запуске база заполняется архивом из `lib/content`.

Переменные в `.env.local` (образец — `.env.example`):

- `ADMIN_USER`
- `ADMIN_PASSWORD`
- `ADMIN_SESSION_SECRET`

На сервере с несколькими копиями процесса положите базу на постоянный диск: `PARDAILABS_DB_PATH`. Без этих переменных вход закрыт.

## Свой API

Если задан `PARDAILABS_API_URL`, сервер запрашивает:

- `GET /articles`
- `GET /services`
- `GET /models`

Ответ — JSON-массив объектов той же формы, что в `lib/types.ts`. Записи с совпадающим `slug` заменяют локальный архив, остальные материалы архива остаются. Если API недоступен, сайт тихо остаётся на локальных данных. Жёсткой привязки к CMS нет.

Адрес сайта для canonical, Open Graph и sitemap: `NEXT_PUBLIC_SITE_URL` (по умолчанию `https://pardailabs.ru`).

Шрифт IBM Plex в `assets/fonts` используется только для картинок Open Graph и распространяется по лицензии OFL (`assets/fonts/OFL.txt`).
